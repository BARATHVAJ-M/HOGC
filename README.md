# HOGC Universe Web Portal

## Overview
The official Sovereign Holding & Foundation website for the House of Giovanni Corsi.

## Tech Stack
- React.js
- Vite
- Vanilla CSS (Luxury Theme)

## Local Development
1. Run `npm install`
2. Run `npm run dev`

## Deployment
This repository is configured to deploy to GitHub Pages.
To deploy, run: `npm run deploy`
